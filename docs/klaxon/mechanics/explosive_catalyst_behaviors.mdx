# Explosive Catalyst Definition

KLAXON's Blast Processors require compatible explosive catalysts in order to function. This page details their exact functions as well as how to configure them.

Explosive Catalysts are defined in two steps:
- **Item Explosion Power Recipes**
    - Determines an Explosive Catalyst's explosion power, whether it produces fire, and whether it's hidden in EMI.
- **Explosive Catalyst Behavior Recipes**
    - Determines the processing that is applied on top of the values sourced from the Item Explosion Power recipe.

## Item Explosion Power Recipes

Example JSON format for an Item Explosion Power recipe.

```
{
  "type": "klaxon:item_explosion_power",
  "explosionPower": 5.0,
  "ingredient": {
    "tag": "yournamespace:yourtag"
  },
  "isHidden": false,
  "producesFire": true
}
```

## Explosive Catalyst Behavior Recipes

Example JSON format for an Explosive Catalyst Behavior recipe.

```
{
  "type": "klaxon:blast_processor_behavior",
  "behavior_id": "klaxon:creeper_head",
  "ingredient": {
    "tag": "your_namespace:your_tag"
  }
}
```
