# Explosive Catalyst Behavior

One of the 3 recipe types used by **Blast Processors**, alongside **Blast Processing** and **Item Explosion Power** recipes.

Explosive Catalyst Behaviors define how an **Explosive Catalyst** is handled. They are prebuilt objects that augment catalyst performance in several ways, including:
- What happens when the Blast Processor produces an explosion
- What items the Blast Processor ejects
- The resultant explosion power of a catalyst
- The recipe output & bounds of a Blast Processor craft
- Whether the Blast Processor should run the default dispenser effects

### Example Explosive Catalyst Behavior Recipe JSON

```
{
  "type": "klaxon:blast_processor_behavior",
  "behavior_id": "klaxon:bedlike_explodable",
  "ingredient": {
    "tag": "klaxon:bedlike_explodables"
  }
}
```

### Good To Know
- If no **Explosive Catalyst Behavior** is defined for an item via JSON, ```klaxon:default``` is used.
