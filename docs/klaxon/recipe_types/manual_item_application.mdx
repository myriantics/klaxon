# Manual Item Application

A *totally original* recipe type that allows you to define an in-world **right click interaction** that uses a defined **ingredient** to convert any block in the defined **block tag** into a defined **result block**.

### Example Manual Item Application Recipe JSON

```
{
  "type": "klaxon:manual_item_application",
  "input": {
    "item": "klaxon:hallnox_pod"
  },
  "output_block": "klaxon:nether_reactor_core",
  "valid_blocks": "#klaxon:manual_item_application/nether_reactor_core_convertible"
}
```

### Good To Know
- All of KLAXON's **Manual Item Application** recipes can be performed by Dispensers.
